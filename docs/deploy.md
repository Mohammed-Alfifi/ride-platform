# التشغيل والنشر المجاني

الهدف: تشغيل المنصة كاملة (قاعدة البيانات، Redis، الـ API، لوحة التشغيل) على خادم واحد مجاني، بعنوانين بشهادة HTTPS، وبناء تطبيقي الجوال للتجربة. هذا مناسب للعرض والتجربة مع شركاء وركاب حقيقيين، لا للإطلاق التجاري.

## الخيار الموصى به: خادم Oracle Cloud المجاني

خادم ARM دائم المجانية: معالجان و12 جيجا ذاكرة (بعد تخفيض Oracle في 2026)، وهذا أكثر من كاف للمنصة. لا ينام مثل الاستضافات المجانية الأخرى، فتعمل المهام اليومية (التجديد 05:00 وفحص الوثائق 06:00) في وقتها.

### 1. إنشاء الخادم
1. سجّل في Oracle Cloud (يطلب بطاقة للتحقق فقط، دون خصم).
2. اختر منطقة رئيسية قريبة، مثل جدة (`me-jeddah-1`)؛ لا يمكن تغييرها لاحقا.
3. Compute → Instances → Create: الصورة Ubuntu 24.04، الشكل `VM.Standard.A1.Flex` بمعالجين و12 جيجا، وأضف مفتاح SSH.
   إن ظهرت رسالة نفاد السعة (Out of capacity) أعد المحاولة لاحقا أو اختر نطاق توفر آخر.
4. في الشبكة (VCN → Security List) أضف قاعدتي دخول: المنفذ 80 والمنفذ 443 من `0.0.0.0/0`.

### 2. العناوين المجانية
من [duckdns.org](https://www.duckdns.org) أنشئ اسمين يشيران لعنوان IP الخادم، مثلا:
- `ride-api.duckdns.org` للـ API
- `ride-admin.duckdns.org` للوحة

(أو نطاقك الخاص لاحقا بسعر رمزي سنويا، بسجلّي A للعنوانين.)

### 3. رفع الكود وتشغيله
على الخادم:
```bash
git clone https://github.com/Mohammed-Alfifi/ride-platform.git   # أو ارفع الملف المضغوط بـ scp
cd ride-platform/infra/server
bash setup.sh ride-api.duckdns.org ride-admin.duckdns.org you@email.com +9665XXXXXXXX
```
السكربت يثبت Docker، ويفتح المنفذين، وينشئ `server.env` بأسرار جديدة، ويبني ويشغل كل شيء، ويطبع رمز الدخول الثابت لرقمك.

ثم أنشئ حساب مدير المنصة بالرقم نفسه:
```bash
bash admin.sh +9665XXXXXXXX "اسمك"
```
افتح `https://ride-admin.duckdns.org` وادخل برقمك والرمز المطبوع.

### 4. بعد التشغيل
- **تحديث الكود:** `bash update.sh` (يسحب الكود، يعيد البناء، والترحيلات تُطبق تلقائيا).
- **نسخ احتياطي يومي:** أضف إلى cron: `0 3 * * * bash ~/ride-platform/infra/server/backup.sh`، وانسخ مجلد `backups` خارج الخادم دوريا.
- **احتفظ بنسخة من `server.env`:** فقد `DATA_ENCRYPTION_KEY` يجعل أرقام الهويات المحفوظة غير قابلة للقراءة.
- **السجلات:** `sudo docker compose logs -f api`

## وضع التشغيل: تجريبي (staging)

الخادم يعمل بـ `NODE_ENV=staging` لأن الإنتاج يرفض شيئين غير جاهزين بعد:
| | الآن (مجاني) | للإطلاق |
| --- | --- | --- |
| رموز الدخول SMS | أرقام تجربة برمز ثابت (`OTP_TEST_PHONES`)؛ وأي رقم آخر يظهر رمزه في سجل الخادم | مزوّد رسائل سعودي (مدفوع بالرسالة) |
| الدفع | صفحة الدفع التجريبية؛ أو مفاتيح Tap التجريبية `sk_test` لصفحات بطاقات حقيقية دون مال حقيقي | مفاتيح Tap الحية بعد حساب التاجر |

لإضافة مختبرين: أضف أرقامهم إلى `OTP_TEST_PHONES` في `server.env` (مفصولة بفواصل) ثم `bash update.sh`.

## تطبيقا الجوال

- **أندرويد (مجاني):** بعد رفع الكود إلى GitHub: Actions → «Android test builds» → Run workflow، وأدخل عنوان الـ API (`https://ride-api.duckdns.org`). بعد دقائق تجد ملفي APK للراكب والسائق في Artifacts؛ أرسلهما للمختبرين للتثبيت مباشرة.
- **آيفون:** يحتاج حساب Apple Developer (رسوم سنوية) للتوزيع عبر TestFlight.
- **المتاجر:** حساب Google Play برسوم لمرة واحدة، و App Store بالاشتراك السنوي أعلاه.

## بديل دون بطاقة: خدمات مجانية متفرقة (للعرض فقط)

| الجزء | الخدمة | العائق |
| --- | --- | --- |
| قاعدة البيانات | Neon (يدعم PostGIS، 1 جيجا) | تتوقف بعد 5 دقائق خمول وتستيقظ مع أول طلب |
| الـ API | Render (خدمة ويب مجانية) | تنام بعد 15 دقيقة دون زيارات، وأول طلب يتأخر نحو دقيقة؛ والملفات المرفوعة تضيع عند كل إعادة تشغيل |
| Redis | Render Key Value | في الذاكرة فقط، يُمسح عند إعادة التشغيل |
| اللوحة | Render أو Vercel | Vercel المجاني للاستخدام غير التجاري فقط |

العائق الأهم: الخادم النائم لا يشغّل التجديد اليومي وفحص الوثائق في وقتهما. لذلك هذا البديل يصلح لعرض الشاشات على مستثمر أو شريك، لا لتجربة اشتراكات حقيقية.
