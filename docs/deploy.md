# التشغيل والنشر المجاني

الهدف: تشغيل المنصة كاملة (قاعدة البيانات، Redis، الـ API، لوحة التشغيل) على خادم واحد مجاني، بعنوانين بشهادة HTTPS، وبناء تطبيقي الجوال للتجربة. هذا مناسب للعرض والتجربة مع شركاء وركاب حقيقيين، لا للإطلاق التجاري.

## الخيار الموصى به: خادم Oracle Cloud المجاني

خادم ARM دائم المجانية: معالجان و12 جيجا ذاكرة (بعد تخفيض Oracle في 2026)، وهذا أكثر من كاف للمنصة. لا ينام مثل الاستضافات المجانية الأخرى، فتعمل المهام اليومية (التجديد 05:00 وفحص الوثائق 06:00) في وقتها.

### 1. إنشاء الخادم
1. سجّل في Oracle Cloud (يطلب بطاقة للتحقق فقط، دون خصم).
2. اختر منطقة رئيسية قريبة، مثل جدة (`me-jeddah-1`)؛ لا يمكن تغييرها لاحقا.
3. Compute → Instances → Create: الصورة Ubuntu 24.04، الشكل `VM.Standard.A1.Flex` بمعالجين و12 جيجا، وأضف مفتاح SSH.
   إن ظهرت رسالة نفاد السعة (Out of capacity) أعد المحاولة لاحقا أو اختر نطاق توفر آخر.
4. في الشبكة (VCN → Security List) أضف قاعدتي دخول: المنفذ 80 والمنفذ 443 من `0.0.0.0/0`.

### 2. العناوين المجانية
من [duckdns.org](https://www.duckdns.org) أنشئ اسمين يشيران لعنوان IP الخادم، مثلا:
- `ride-api.duckdns.org` للـ API
- `ride-admin.duckdns.org` للوحة

(أو نطاقك الخاص لاحقا بسعر رمزي سنويا، بسجلّي A للعنوانين.)

### 3. رفع الكود وتشغيله
على الخادم:
```bash
git clone https://github.com/Mohammed-Alfifi/ride-platform.git   # أو ارفع الملف المضغوط بـ scp
cd ride-platform/infra/server
bash setup.sh ride-api.duckdns.org ride-admin.duckdns.org you@email.com
```
السكربت يثبت Docker، ويفتح المنفذين، وينشئ `server.env` بأسرار جديدة، ويبني ويشغل كل شيء.

ثم أنشئ حساب مدير المنصة بالرقم نفسه:
```bash
bash admin.sh +9665XXXXXXXX "اسمك"
```
يطبع الأمر رمز دخول من 8 أرقام. افتح `https://ride-admin.duckdns.org` وادخل برقمك وهذا الرمز. لرمز جديد في أي وقت: `bash code.sh 05XXXXXXXX`.

### 4. بعد التشغيل
- **تحديث الكود:** `bash update.sh` (يسحب الكود، يعيد البناء، والترحيلات تُطبق تلقائيا).
- **نسخ احتياطي يومي:** أضف إلى cron: `0 3 * * * bash ~/ride-platform/infra/server/backup.sh`، وانسخ مجلد `backups` خارج الخادم دوريا.
- **احتفظ بنسخة من `server.env`:** فقد `DATA_ENCRYPTION_KEY` يجعل أرقام الهويات المحفوظة غير قابلة للقراءة.
- **السجلات:** `sudo docker compose logs -f api`

## نسخة مجانية على Render بضغطة واحدة

أسرع طريقة لرابط يعمل على الإنترنت، دون خادم خاص بك:

1. افتح [render.com/deploy?repo=https://github.com/Mohammed-Alfifi/ride-platform](https://render.com/deploy?repo=https://github.com/Mohammed-Alfifi/ride-platform) وسجّل الدخول بحساب GitHub.
2. يطلب ثلاث قيم:
   - `SUPER_ADMIN_PHONE`: جوالك بصيغة `+9665XXXXXXXX`.
   - `OTP_TEST_PHONES`: نفس الجوال.
   - `OTP_TEST_CODE`: رمز من 6 أرقام تختاره لدخولك.
3. اضغط Apply وانتظر 10 إلى 15 دقيقة حتى تكتمل الخدمات الخمس.

الروابط:
- **اللوحة:** `https://mishwar-ride-admin.onrender.com`، وتدخلها بجوالك ورمزك.
- **صفحة الانضمام:** `https://mishwar-ride-admin.onrender.com/join`.
- **تطبيق الراكب في المتصفح:** `https://mishwar-ride-app.onrender.com`.

حدود الخطة المجانية:
- الخادم واللوحة ينامان بعد 15 دقيقة دون زيارات، وأول فتح بعدها يأخذ قرابة دقيقة.
- قاعدة البيانات المجانية تُحذف بعد 30 يوما.
- الملفات المرفوعة، مثل وثائق السائقين، تضيع عند إعادة التشغيل.

هذه النسخة مناسبة للعرض والتجربة القصيرة. للتجربة الحقيقية استخدم خادم Oracle المجاني أدناه.

### إبقاء الخادم مستيقظا (مجانا)
المستودع فيه بوت (`.github/workflows/keep-alive.yml`) يزور الخادم كل 10 دقائق من 5 صباحا إلى 10 مساء بتوقيت الرياض، فلا ينام أثناء ساعات التشغيل. يعمل تلقائيا على GitHub دون إعداد.

- **لماذا ليس طوال اليوم:** خطة Render المجانية تعطي 750 ساعة في الشهر لكل الخدمات معا، وتوقف كل الخدمات حتى بداية الشهر التالي إذا نفدت. إبقاء الخادم 24 ساعة يستهلك قرابة 744 ساعة وحده، فلا يبقى شيء للوحة. أما 17 ساعة يوميا فتستهلك قرابة 530 ساعة، ويبقى قرابة 220 ساعة للوحة.
- **لتغيير العنوان دون تعديل الملف:** في GitHub افتح Settings ← Secrets and variables ← Actions ← Variables، وأضف `KEEPALIVE_URLS`.
- **تنبيه مجاني:** إذا لم يرد الخادم يفشل البوت، ويرسل لك GitHub بريدا.
- **ملاحظة:** GitHub يوقف المهام المجدولة في المستودعات العامة بعد 60 يوما بلا أي تحديث. أي رفع للكود يعيد تشغيلها.

### حفظ وثائق السائقين مجانا (Cloudflare R2)
قرص الخادم المجاني يُمسح عند كل إعادة تشغيل. احفظ الملفات في Cloudflare R2، ومساحته المجانية 10 جيجا:
1. أنشئ حسابا في Cloudflare، ثم R2 ← Create bucket باسم `mishwar-docs`.
2. من Manage R2 API Tokens أنشئ مفتاحا بصلاحية Object Read & Write.
3. في Render، في Environment لخدمة الخادم، ضع:
   - `STORAGE_DRIVER=s3`
   - `S3_BUCKET=mishwar-docs`
   - `S3_REGION=auto`
   - `S3_ENDPOINT=https://<ACCOUNT_ID>.r2.cloudflarestorage.com`
   - `S3_ACCESS_KEY_ID` و `S3_SECRET_ACCESS_KEY`: من المفتاح الذي أنشأته.

### مراقبة الأداء
صفحة «حالة النظام» في اللوحة، وتظهر لمدير المنصة فقط، تعرض:
- سرعة كل مسار وأخطاءه في آخر 15 دقيقة.
- حالة قاعدة البيانات و Redis.
- آخر تشغيل لكل مهمة آلية.
- عنوانك كما يراه الخادم.

إذا ظهر في هذه الصفحة عنوان خوادم Render بدل عنوانك الحقيقي، عدّل `TRUST_PROXY_HOPS`، لأن حدود المحاولات تعمل لكل عنوان.

### التوسع لأكثر من خادم
الخادم لا يحفظ شيئا في ذاكرته يحتاجه خادم آخر:
- الجلسات وحدود المحاولات ومواقع السائقين والمهام الآلية في Redis.
- الملفات في R2.

لذلك يمكن تشغيل عدة نسخ من الخادم خلف موزّع حمل دون تعديل الكود، والمهام اليومية تعمل مرة واحدة مهما كان عدد النسخ. على Render يتطلب هذا خطة مدفوعة.

كل رفع للكود يشغّل اختبار ضغط تلقائيا على GitHub: 1,500 مشترك وقرابة 186 ألف رحلة، ويفشل البناء إذا أبطأ أي مسار مهم عن حده.

## وضع التشغيل: تجربة مغلقة دون تكاليف

الإعدادات الافتراضية تشغّل الخادم بوضع الإنتاج (`NODE_ENV=production`) دون أي خدمة مدفوعة:

| | الآن (مجاني) | عند التوسع |
| --- | --- | --- |
| الدخول | بالدعوة فقط، برمز من 8 أرقام ترسله من اللوحة بالواتساب | مزوّد SMS سعودي: `SMS_PROVIDER=taqnyat` |
| الدفع | تحويل بنكي أو نقدا، تسجله من اللوحة فتصدر الفاتورة | Tap: `PAYMENT_PROVIDER=tap` مع المفاتيح |

التفاصيل وإجراءات التشغيل اليومي في [`pilot.md`](pilot.md).

## تطبيقا الجوال

- **أندرويد والآيفون (مجاني):** من GitHub: Actions → «Release builds» → Run workflow، وأدخل عنوان الـ API (`https://ride-api.duckdns.org`). يُنشر إصدار فيه تطبيقا أندرويد موقّعان ونسخة الويب للآيفون. ثم على الخادم `bash update.sh` لتنزيل نسخة الويب، فتعمل على `https://ride-api.duckdns.org/app/`. صفحة `https://ride-admin.duckdns.org/download` تشرح التثبيت للعملاء.
- **المتاجر لاحقا:** حساب Google Play برسوم لمرة واحدة، و App Store باشتراك سنوي.

## بديل دون بطاقة: خدمات مجانية متفرقة (للعرض فقط)

| الجزء | الخدمة | العائق |
| --- | --- | --- |
| قاعدة البيانات | Neon (يدعم PostGIS، 1 جيجا) | تتوقف بعد 5 دقائق خمول وتستيقظ مع أول طلب |
| الـ API | Render (خدمة ويب مجانية) | تنام بعد 15 دقيقة دون زيارات، وأول طلب يتأخر نحو دقيقة؛ والملفات المرفوعة تضيع عند كل إعادة تشغيل |
| Redis | Render Key Value | في الذاكرة فقط، يُمسح عند إعادة التشغيل |
| اللوحة | Render أو Vercel | Vercel المجاني للاستخدام غير التجاري فقط |

العائق الأهم: الخادم النائم لا يشغّل التجديد اليومي وفحص الوثائق في وقتهما. لذلك هذا البديل يصلح لعرض الشاشات على مستثمر أو شريك، لا لتجربة اشتراكات حقيقية.
